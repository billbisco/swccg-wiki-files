    Post by Munchanka » August 20th, 2017, 2:37 pm

    'Last Jedi Standing' tournament
    Endgame game store, Oakland CA
    August 19, 10am-6pm
    Three round, six game Swiss-Style tournament
    Format: Sealed Jabba's Palace, Cloud City, and Premiere packs

    Players:
    John Borba
    Benjamin Arthur Christopher
    Mark Fisher
    Chris Hunter
    Mach Kobayashi
    Austin Madison
    Andrew Peterson
    Christopher Peterson
    Tim Pixton
    Sam Salzeider
    Alexander Sheynis
    Gibson Yim

    We used the new tournament software, which was fantastic! We had a player drop-out, which was no problem. I wasn't sure how to do BYEs only for the 1st game, since Alexander and I wanted to help out new players (four of our players were totally new to the game), so you'll see 'Proxy 1' and 'Proxy 2' as my version of a BYE for the first game.

    Final rankings:
    1st Gibson Yim: 6-0, SoS 37, Diff 47 (FLAWLESS VICTORY!)
    2nd Austin Madison: 5-1, SoS 32, Diff 41
    3rd Boneyard Sheynis: 4-2, SoS 47, Diff 1
    4th Sam Salzeider: 4-2, SoS 43, Diff 18
    5th Christopher Peterson: 4-2, SoS 38, Diff 25
    6th Tim Pixton: 3-3, SoS 49, Diff 2
    7th Benjamin Arthur Christopher: 3-3, SoS 32, Diff -7
    8th John Borba: 3-3, SoS 31, Diff -7
    9th Andrew Peterson: 2-4, SoS 41, Diff -36
    10th Mark Fisher: 2-4, SoS 34, Diff -34
    11th Mach Tony Kobayashi: 1-5, SoS 37, Diff -51
    12th Chris Hunter: 1-2, SoS 24, Diff 1
