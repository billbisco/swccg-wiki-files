    So it's been a while coming and I think it's time to run the next Gempc!


    I will setup a league so prizes can be won through the actual Gemp program

    If there is interest we can do entry fee for prizes but that's a voting thing

    Since there will be prizes, to sign up I will need these private messaged to me:

    1. Real Name
    2. email address
    3. Forum name
    4. Gemp Name

    Currently there is no charge to play

    Format:
    Match Play (you Play both sides counting differential to see who wins the match)
    Constructed Open (this means with shields too)
    May Change Decks between Rounds

    Gemp is an ever changing meta as more and more cards are added. The latest cards added to the server will be legal throughout the event
